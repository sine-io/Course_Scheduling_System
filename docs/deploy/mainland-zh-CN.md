# 中国大陆部署与天津初中草稿流程

本页适用于中国大陆学校部署。系统通过部署级配置档启用简体中文和中国大陆术语，当前针对天津初中提供“草稿”模板。铃声、每周课时和校历不会由系统猜测，必须由学校教务人员补充并确认。

## 1. 首次部署

复制配置文件并至少修改管理员密码、学校名称和随机密钥：

```bash
cp .env.example .env
openssl rand -hex 32
```

在 `.env` 中设置：

```ini
SCHOOL_PROFILE=cn_mainland
SCHOOL_NAME=学校名称
SECRET_KEY=上一步生成的随机字符串
```

中国大陆档固定使用 `zh-CN` 和 `Asia/Shanghai`。`TZ` 即使填写其他值也不会覆盖该规则。

启动服务：

```bash
sudo docker compose pull
sudo docker compose up -d
sudo docker compose ps
```

首次启动会执行数据库迁移。可以访问 `http://主机地址/api/app-config` 检查公开配置；该接口不返回密码、数据库连接或其他机密。

## 2. 配置档锁定

系统第一次成功写入数据库时保存 `SCHOOL_PROFILE`。之后修改环境变量为另一地区会返回 `409 school_profile_locked`，不会自动转换已有学期数据。

旧版本数据库如果已经存在学期，升级后按台湾旧部署处理。要建立大陆部署，请使用新数据库或先按备份流程完成独立迁移。

## 3. 建立天津初中草稿学期

登录后进入“设置向导”或“学期与节次表”：

1. 选择“天津初中（草稿）”。
2. 创建 `2026` 学年起始年的学期。界面显示为 `2026-2027学年第一学期`。
3. 打开“初中节次表（待编辑）”，按学校正式材料填写周一至周六的节次、名称、起止时间和不可排课格。
4. 在基础资料中确认科目、教师、班级、班主任和专用教室；可下载简体中文 Excel 导入模板。

草稿模板只包含可编辑的科目种子和空白节次表，不包含铃声、周课时或固定校历。

## 4. 维护校历并确认就绪

进入“校历与就绪”，选择学期后维护例外日期：

- **停课**：当天不生成请假受影响节次。
- **补课**：必须指定使用周一至周六中的哪一天课表，例如周六使用“周一课表”。

日期不能重复，且必须位于学期起止日期内。修改学期日期、节次表或校历例外会自动撤回“已就绪”状态。

确认前至少需要：

- 学期起止日期；
- 至少一套节次表；
- 至少一个可排课节次。

确认成功后，学期状态变为“已就绪”。大陆草稿学期在确认前不能自动排课，也不能发布课表；接口会返回 `409 semester_not_ready` 及具体检查项。

## 5. 升级与备份

升级前先备份，再使用同一份配置档：

```bash
sudo docker compose exec worker-ops pg_dump -Fc -h postgres -U scheduler -d scheduler \
  -f /backups/manual_$(date +%Y%m%d_%H%M%S).dump
sudo docker compose up -d
```

不要在已有台湾学期的数据库上直接改成 `cn_mainland`。如需跨地区迁移，先导出并由管理员确认日期、科目、节次表和校历后再建立新的大陆部署。

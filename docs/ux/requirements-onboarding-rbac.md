# 上手引导与角色导航需求基线

本文记录“功能分类、常用入口和 RBAC”对齐后的产品需求。它是后续实现和验收的基线，不是页面设计稿。

## 目标

让没有使用经验的排课管理员，在不阅读完整手册的情况下，沿着一条清晰路径完成正式学期的第一张可用课表；同时让教师和教务主任只看到与职责相关的入口。

## 功能优先级

| 优先级 | 目标 | 范围 |
|---|---|---|
| P0 | 首次成功 | 设置向导、学期与作息、校历、基础数据、教学任务、自动/手动排课、完整性检查、版本发布、课表查询 |
| P1 | 日常运行 | 请假、调课与代课、今日看板、通知、记录、课时统计、常用导出 |
| P2 | 高级排课 | 多草稿、混合学制、走班、协同教学、连堂、复杂约束、部分排课、无解定位 |
| P3 | 系统运维 | 账号权限、学校设置、备份恢复、审计、SMTP、升级和健康检查 |

## 导航结构

顶部工具栏只承载当前学校/当前学期、通知、帮助和账号等全局上下文；不放删除、发布、恢复等高风险动作。

侧边栏第一组为“常用”，最多五项；下方保留完整功能目录，按“学期准备、排课主流程、日常运行、报表、系统管理”分组。

常用入口使用“角色默认值 + 阶段化推荐 + 用户固定/排序 + 最近访问补位”的规则。用户可以恢复默认，但不能通过常用入口绕过权限、检查、确认或审计。

## 角色与默认常用入口

| 角色 | 权限定位 | 首次发布前 | 首次发布后 |
|---|---|---|---|
| 系统管理员 | 全部系统和业务权限 | 仪表盘、系统管理、备份恢复、账号权限、上手指南 | 仪表盘、系统管理、备份恢复、账号权限、课表查询 |
| 排课管理员 | 教学任务、排课草稿、排课运行和发布 | 当前待办、教学任务、自动排课、排课工作台、版本与发布 | 仪表盘、课表查询、今日看板、调课与代课、版本与发布 |
| 教务主任 | 全校监督和有限日常运行操作 | 仪表盘、课表查询、今日看板、版本与发布、代课课时统计 | 仪表盘、课表查询、今日看板、版本与发布、代课课时统计 |
| 教师 | 已发布课表和本人事务 | 课表查询、请假登记、通知、我的代课课时 | 课表查询、请假登记、通知、我的代课课时 |

一个用户可以同时拥有多个角色。权限取并集；只要拥有排课管理员角色，默认进入管理视角，不提供会改变授权结果的角色切换器。

## 动作权限基线

| 动作 | 系统管理员 | 排课管理员 | 教务主任 | 教师 |
|---|---:|---:|---:|---:|
| 查看已发布课表 | 是 | 是 | 是 | 是 |
| 查看排课草稿 | 是 | 是 | 是 | 否 |
| 编辑基础数据 | 是 | 是 | 否 | 否 |
| 编辑教学任务/排课草稿 | 是 | 是 | 否 | 否 |
| 运行自动排课 | 是 | 是 | 否 | 否 |
| 发布课表 | 是 | 是 | 否 | 否 |
| 维护校历 | 是 | 是 | 是 | 否 |
| 登记或处理全校请假 | 是 | 是 | 是 | 否 |
| 处理调课与代课 | 是 | 是 | 是 | 仅确认本人通知 |
| 修改本人请假/确认本人通知 | 是 | 是 | 是 | 是 |
| 单张已发布课表导出 | 是 | 是 | 是 | 是 |
| 批量或版本级导出 | 是 | 是 | 否 | 否 |
| 备份与恢复 | 是 | 否 | 否 | 否 |
| 账号和角色管理 | 是 | 否 | 否 | 否 |

前端隐藏菜单只改善体验，后端必须对每个动作再次校验。高风险动作包括发布、删除、备份恢复和权限变更，必须确认并留下审计记录。

## 学期和引导状态

- 首次进入提供“示例数据体验”和“正式建校”两条路径。
- 设置向导完成不等于首次成功。
- 首次成功条件：当前正式学期存在一张通过完整性检查、没有必排教学任务遗漏并已发布的课表。
- 仪表盘在达到首次成功前持续显示 P0 待办。
- 学校只有一个当前学期；历史或归档学期默认只读，可查询和复制。
- 只有系统管理员或排课管理员可以切换当前学期。

## 第一阶段验收场景

1. 全新系统能明确选择示例体验或正式建校。
2. 示例路线能完成一次自动排课并看到发布结果。
3. 正式路线在首次发布前持续显示 P0 待办。
4. 教师看不到草稿，不能编辑他人的请假或课表。
5. 教务主任能查看全校数据并处理日常调课代课，但不能发布课表。
6. 排课管理员兼教师时，权限取并集并默认进入管理视角。
7. 历史/归档学期默认只读，不能误发布。

## 明确不纳入第一阶段

自定义角色编辑器、发布审批流、复杂组织架构权限、完全自由的菜单布局编辑器，以及把高风险动作变成一键执行。

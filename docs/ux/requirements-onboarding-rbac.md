# 学期准备与角色导航需求基线

本文记录“功能分类、仪表盘快捷入口和 RBAC”对齐后的产品需求。导航部分以 ADR-0005、ADR-0016、ADR-0018 为准，学期准备以 ADR-0010、ADR-0018 为准；本文是业务验收基线，不是页面设计稿。

## 目标

让没有使用经验的教务主任通过真实业务页面建立学校的排课基础；同时让教师只看到与本人事务相关的入口，并确保管理员专属入口只向内置系统管理员开放。

## 功能优先级

| 优先级 | 目标 | 范围 |
|---|---|---|
| P0 | 建校与排课 | 学期与作息、校历、基础数据、教学任务、自动/手动排课、排课前置检查、版本发布、课表查询 |
| P1 | 日常运行 | 请假、调课与代课、今日看板、通知、记录、课时统计、常用导出 |
| P2 | 高级排课 | 多草稿、混合学制、走班、协同教学、连堂、复杂约束、部分排课、无解定位 |
| P3 | 系统运维 | 账号权限、学校设置、备份恢复、审计、SMTP、升级和健康检查 |

## 导航结构

顶部工具栏只承载当前学校/当前学期、通知、帮助和账号等全局上下文；不放删除、发布、恢复等高风险动作。

侧边栏直接按“工作空间、排课主流程、日常运行、报表、系统管理”五组展示获准页面；学期准备能力收纳在排课工作台的辅助工作面，仪表盘和排课工作台位于工作空间，仪表盘继续提供每个角色最多三个固定快捷入口。

快捷入口由角色职责固定决定，不保存个人固定、排序或最近访问状态，也不能绕过权限、检查、确认或审计。

## 角色与默认快捷入口

| 角色 | 权限定位 | 仪表盘快捷入口 |
|---|---|---|---|
| 内置系统管理员 | 全部系统和业务权限；独占系统级管理 | 排课工作台、课程表调整、版本与发布 |
| 教务主任 | 除管理员专属功能外的全部学校教务业务 | 排课工作台、课程表调整、版本与发布 |
| 教师 | 已发布课表和本人事务 | 课表查询、请假登记、通知 |

一个用户可以同时拥有多个角色。权限取并集；只要拥有教务主任角色，默认进入管理视角，不提供会改变授权结果的角色切换器。

## 动作权限基线

| 动作 | 内置系统管理员 | 教务主任 | 教师 |
|---|---:|---:|---:|
| 查看已发布课表 | 是 | 是 | 是 |
| 查看排课草稿 | 是 | 是 | 否 |
| 编辑基础数据 | 是 | 是 | 否 |
| 编辑教学任务/排课草稿 | 是 | 是 | 否 |
| 运行自动排课 | 是 | 是 | 否 |
| 发布课表 | 是 | 是 | 否 |
| 维护校历 | 是 | 是 | 否 |
| 登记或处理全校请假 | 是 | 是 | 否 |
| 处理调课与代课 | 是 | 是 | 仅确认本人通知 |
| 修改本人请假/确认本人通知 | 是 | 是 | 是 |
| 单张已发布课表导出 | 是 | 是 | 是 |
| 批量或版本级导出 | 是 | 是 | 否 |
| 备份与恢复 | 是 | 否 | 否 |
| 账号和角色管理 | 是 | 否 | 否 |

前端隐藏菜单只改善体验，后端必须对每个动作再次校验。高风险动作包括发布、删除、备份恢复和权限变更，必须确认并留下审计记录。

## 学期准备

- 首次使用从“排课工作台”的学期创建卡片开始，创建带真实起止日期的中性学期；不显示路线选择，也不按学校类型隐式生成数据。
- 学期、基础数据、作息分组和校历在排课工作台的对应辅助工作面或五步档案视图维护，复用同一组真实业务数据。批量导入 API 保留用于兼容已有集成，但不提供独立的跨页面引导入口。
- 仪表盘只显示当前学期的中性数据摘要；教室、教师账号、特殊日期和作息缺项等事实性提醒直接链接到工作台对应辅助工作面。
- 排课前置检查区分阻断项和建议项；它只决定排课动作是否可继续，不代表学期准备完成，也不代表课表已发布。
- 产品不提供内置示例学校、独立的新手完成状态或跨页面准备进度；Excel 导入模板中的示范行只用于说明填写格式。
- 学校只有一个当前学期；历史或归档学期默认只读，可查询和复制。
- 只有系统管理员或教务主任可以切换当前学期。

## 第一阶段验收场景

1. 全新系统进入“排课工作台”的“学期管理”辅助工作面后，可以创建中性学期，并明确不会自动生成科目、教师、班级或作息。
2. 学期、基础数据、作息分组和校历可以从工作台的对应辅助工作面分别保存并再次打开；仪表盘摘要始终来自真实数据。
3. 无学期空状态把管理角色直接带到排课工作台创建学期，教师只看到联系教务主任的说明。
4. 教师看不到草稿，不能编辑他人的请假或课表。
5. 教务主任能查看并编辑全校业务数据，处理日常调课代课并发布课表；不能访问管理员专属功能。
6. 教务主任兼教师时，权限取并集并默认进入管理视角。
7. 历史/归档学期默认只读，不能误发布。

## 明确不纳入第一阶段

自定义角色编辑器、发布审批流、复杂组织架构权限、完全自由的菜单布局编辑器，以及把高风险动作变成一键执行。

# 设置向导与角色导航需求基线

本文记录“功能分类、仪表盘快捷入口和 RBAC”对齐后的产品需求。导航部分已由 ADR-0005 更新；本文是业务验收基线，不是页面设计稿。

## 目标

让没有使用经验的排课管理员直接通过五步设置向导建立学校的排课基础；同时让教师和教务主任只看到与职责相关的入口。

## 功能优先级

| 优先级 | 目标 | 范围 |
|---|---|---|
| P0 | 建校与排课 | 设置向导、学期与作息、校历、基础数据、教学任务、自动/手动排课、完整性检查、版本发布、课表查询 |
| P1 | 日常运行 | 请假、调课与代课、今日看板、通知、记录、课时统计、常用导出 |
| P2 | 高级排课 | 多草稿、混合学制、走班、协同教学、连堂、复杂约束、部分排课、无解定位 |
| P3 | 系统运维 | 账号权限、学校设置、备份恢复、审计、SMTP、升级和健康检查 |

## 导航结构

顶部工具栏只承载当前学校/当前学期、通知、帮助和账号等全局上下文；不放删除、发布、恢复等高风险动作。

侧边栏直接按“学期准备、排课主流程、日常运行、报表、系统管理”五组展示获准页面；仪表盘提供每个角色最多三个固定快捷入口。

快捷入口由角色职责固定决定，不保存个人固定、排序或最近访问状态，也不能绕过权限、检查、确认或审计。

## 角色与默认快捷入口

| 角色 | 权限定位 | 仪表盘快捷入口 |
|---|---|---|---|
| 系统管理员 | 全部系统和业务权限 | 排课工作台、教学任务、今日看板 |
| 排课管理员 | 教学任务、排课草稿、排课运行和发布 | 排课工作台、教学任务、今日看板 |
| 教务主任 | 全校监督和有限日常运行操作 | 课表查询、今日看板、版本与发布 |
| 教师 | 已发布课表和本人事务 | 课表查询、请假登记、通知 |

一个用户可以同时拥有多个角色。权限取并集；只要拥有排课管理员角色，默认进入管理视角，不提供会改变授权结果的角色切换器。

## 动作权限基线

| 动作 | 系统管理员 | 排课管理员 | 教务主任 | 教师 |
|---|---:|---:|---:|---:|
| 查看已发布课表 | 是 | 是 | 是 | 是 |
| 查看排课草稿 | 是 | 是 | 是 | 否 |
| 编辑基础数据 | 是 | 是 | 否 | 否 |
| 编辑教学任务/排课草稿 | 是 | 是 | 否 | 否 |
| 运行自动排课 | 是 | 是 | 否 | 否 |
| 发布课表 | 是 | 是 | 否 | 否 |
| 维护校历 | 是 | 是 | 是 | 否 |
| 登记或处理全校请假 | 是 | 是 | 是 | 否 |
| 处理调课与代课 | 是 | 是 | 是 | 仅确认本人通知 |
| 修改本人请假/确认本人通知 | 是 | 是 | 是 | 是 |
| 单张已发布课表导出 | 是 | 是 | 是 | 是 |
| 批量或版本级导出 | 是 | 是 | 否 | 否 |
| 备份与恢复 | 是 | 否 | 否 | 否 |
| 账号和角色管理 | 是 | 否 | 否 | 否 |

前端隐藏菜单只改善体验，后端必须对每个动作再次校验。高风险动作包括发布、删除、备份恢复和权限变更，必须确认并留下审计记录。

## 学期和设置向导

- 全新管理用户进入后直接开始学制模板、学年学期、作息时间表、基础数据导入和完成确认五个步骤，不显示路线选择。
- 向导保存当前步骤和正在设置的学期，中断或重新登录后继续原进度；完成后进入教学任务管理。
- 设置向导不作为持久侧栏入口；无学期时仪表盘显示“前往设置向导”，系统管理可重新启动向导。
- 产品不提供内置示例学校或独立的新手完成状态；Excel 导入模板中的示范行只用于说明填写格式。
- 学校只有一个当前学期；历史或归档学期默认只读，可查询和复制。
- 只有系统管理员或排课管理员可以切换当前学期。

## 第一阶段验收场景

1. 全新系统进入向导后直接显示“学制模板”步骤，不出现路线选择或内置示例数据入口。
2. 向导中断后能恢复步骤，完成后进入教学任务管理；跳过、系统管理重启向导和角色权限保持可用。
3. 仪表盘不显示持续的新手路径卡片，无学期空状态仍可进入向导。
4. 教师看不到草稿，不能编辑他人的请假或课表。
5. 教务主任能查看全校数据并处理日常调课代课，但不能发布课表。
6. 排课管理员兼教师时，权限取并集并默认进入管理视角。
7. 历史/归档学期默认只读，不能误发布。

## 明确不纳入第一阶段

自定义角色编辑器、发布审批流、复杂组织架构权限、完全自由的菜单布局编辑器，以及把高风险动作变成一键执行。

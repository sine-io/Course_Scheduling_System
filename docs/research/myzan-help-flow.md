# MyZan 排课流程研究记录

状态：已完成。

研究日期：2026-08-31

## 来源与抓取说明

主要来源是 MyZan 的公开操作说明：<https://www.myzan.cn/help/>。研究时原站首页和部分页面由上游网关返回 502，因此使用只读的文本镜像完成抓取；下面的链接仍然指向原始页面，内容以原站说明为准。

## 主流程事实

MyZan 在首次启动说明中把最短可记忆路径明确写成：

> 设置班级 → 设置课时 → 科目节数 → 教师任课 → 开始排课

完成自动排课后，用户打开课程表进行手工调整和打印。主流程原文见[主界面说明](https://www.myzan.cn/help/index.html)。

各步的业务输入和输出如下：

| 原流程 | 关键输入 | 完成后可继续的动作 |
| --- | --- | --- |
| 设置班级 | 年级组、班级名称；支持 Excel 导入 | 设置课时 |
| 设置课时 | 上课日、每天各时段节数、免任课位置；可选节次时间和公共时段 | 设置科目节数 |
| 科目节数 | 科目简称、各年级/班级周课时、公共场室或同科上限、连堂次数 | 教师任课 |
| 教师任课 | 教师、教师与教学任务的分配；可批量录入或拖拽 | 查看规则并开始排课 |
| 开始排课 | 排课范围、预排、自动排课强度、教师课时分散/集中、连堂等条件 | 打开课程表 |
| 课程表操作 | 班级/教师/总表/场室视角、拖动、锁定、撤销 | 手工调整、打印、导出 |

容量是显式的前置约束：每个班级的科目节数合计不能超过由上课日、每天节数和免任课位置计算出的课时容量；超出时会有预警。详见[课时设置](https://www.myzan.cn/help/2.html)和[科目节数](https://www.myzan.cn/help/3.html)。

## 辅助设置事实

辅助设置不改变五步主路径，但会影响自动排课结果：

- [合班设置](https://www.myzan.cn/help/8.html)：同一教师、同一科目、不同班级才可合班；排好课后修改会把相关课程放回暂放区。
- [科目排课位置](https://www.myzan.cn/help/keyupai.html)和[预排](https://www.myzan.cn/help/9.html)：按学校、年级或班级指定“不排、一定排、尽量排”的课节位置。
- [自定义排课条件](https://www.myzan.cn/help/10.html)：支持时段限制、各天限制、教师互斥、科目互斥和禁止科目相邻。
- [公共场室](https://www.myzan.cn/help/7.html)：场室容量按可同时容纳的班级数填写。

这些设置应该在“自动排课”前可见，但不应被隐藏在一次不可解释的总分或魔法按钮之后。

## 课表后续事实

[课程表操作](https://www.myzan.cn/help/6.html)同时提供班级、教师、总课程表、总任课表和场室视角；拖动课程时即时提示能否调整，锁定可避免后续操作移动指定课位，并支持撤销/重做。未能安排的课程进入暂放区，用户可以继续手工处理或重新排课。

输出是排课完成后的动作，而不是自动排课的隐式副作用：[班级/教师表](https://www.myzan.cn/help/6_pr.html)、[总课程表/总任课表](https://www.myzan.cn/help/6_prAll.html)和[调课通知](https://www.myzan.cn/help/6_tiaoke.html)分别服务不同的打印和导出场景。

学期中调课与代课另有独立边界：[临时调课与代课](https://www.myzan.cn/help/22.html)通过任务继承保留原始课表，不应被期初排课流程混在一起。

## 对本项目的启示

1. 保留一条五步记忆路径，降低首次排课的认知负担。
2. 把规则、预排和前置检查放在生成前的可展开区域，清楚区分“要上什么课”和“这些课怎样安排”。
3. 生成后直接进入多视角检查工作台，未排课时、冲突、锁定和局部重排应在同一上下文中完成。
4. 输出和发布应是显式的最后阶段；学期中调课与代课继续留在日常运行流程。
5. 对本项目而言，这些连接应由现有业务数据推导，不再复制一套“设置完成”或向导进度状态。

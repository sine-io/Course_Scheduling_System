# 透明的中性学期初始化

状态：部分由 ADR-0010 取代；基础数据手工录入入口条款由 ADR-0017、ADR-0018 取代。保留本文记录中性学期数据决策；当前产品不再提供设置向导。

学期创建不要求用户选择学校级“学制模板”，也不按某个学制偷偷生成科目或作息。创建只产生学期外壳，随后由用户在排课工作台的学期管理、资源与导入辅助工作面及五步档案视图录入真实数据，并通过可预览的配置器建立一个或多个作息分组。这样保留班级级学制和混合学制能力，同时避免把初始化方案误解为学校的全局学制；排课准备和课表发布仍由后续业务流程负责。

## 后果

- 学期准备的业务职责仍分别保存真实数据，现行用户入口收敛为排课工作台的学期管理、校历与准备、资源与导入辅助工作面及五步档案视图；用户可以按任意顺序返回修改。
- “学校模板”入口从新建学期和新增作息时间表中移除；快捷起稿必须展示可编辑参数和预览，并由用户确认后写入。
- 基础数据步骤直接展示手工录入工作面，不提供批量/手工模式切换。既有组合 Excel 导入 API 保留兼容性；教师账号不属于初始基础数据录入。
- 系统管理不再提供重新启动入口；工作台辅助工作面分别维护当前学期，不清空已有数据或创建重复学期。旧地址只作为兼容跳转保留。

# 设置向导使用透明的中性初始化

状态：已接受。

设置向导不再要求用户选择学校级“学制模板”，也不按某个学制偷偷生成科目或作息。第一步只创建学期外壳，随后由用户导入或明确选择基础数据，并通过可预览的作息配置器建立一个或多个作息分组。这样保留班级级学制和混合学制能力，同时避免把初始化方案误解为学校的全局学制；向导完成只表示基础设置完成，排课准备和课表发布仍由后续业务流程负责。

## 后果

- 设置向导收敛为“学校与学期 → 基础数据 → 作息安排 → 完成检查”四步；中途可保存并退出，仪表盘提供恢复入口。
- “学校模板”入口从新建学期和新增作息时间表中移除；快捷起稿必须展示可编辑参数和预览，并由用户确认后写入。
- 组合 Excel 导入先校验和预览，再以一个事务写入；教师账号不属于初始基础数据导入。
- 系统管理中的重新启动入口改为检查并补全当前学期，不清空现有向导绑定或创建重复学期。

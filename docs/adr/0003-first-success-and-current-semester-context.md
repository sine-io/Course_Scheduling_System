# 首次成功引导与当前学期上下文

状态：部分由 ADR-0006 取代。首次成功引导、示例数据和双路线决策不再适用；当前学期上下文决策仍然有效。

系统把“设置向导完成”和“首次成功”作为两个不同状态：向导只负责建立学期、作息和基础数据，首次成功持续到当前正式学期存在一张通过完整性检查、没有必排教学任务遗漏并已发布的课表。正式数据和示例数据在首次进入时提供两条明确路径，示例体验不能替代正式学期的首次成功。业务页面以一个可切换的“当前学期”作为默认上下文，历史或归档学期可查询和复制但默认只读，不应与当前教学工作混用。这样既保留示例数据带来的低学习成本，也避免用户把完成配置误认为已经完成排课。

## 后果

- 仪表盘需要显示 P0 待办，直到当前正式学期首次发布课表。
- 切换到历史或非当前学期时，界面必须明确当前上下文，并限制常规写入和发布动作；只有系统管理员或排课管理员可以切换当前学期。
- 示例数据体验不能悄悄改变正式学期的引导状态。

## 首屏引导顺序

首次发布前后的引导列表只在仪表盘和设置向导中展示，不占用侧边栏入口。仪表盘快捷入口按角色固定：排课管理角色进入排课工作台、教学任务和今日看板；教师进入课表查询、请假和通知；教务主任进入课表查询、今日看板和版本监督。具体导航结构和通知视图见 ADR-0005。

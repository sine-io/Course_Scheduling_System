# 首次成功引导与当前学期上下文

状态：首次成功引导、示例数据和双路线决策不再适用；当前学期上下文决策仍然有效。初始准备流程由 [ADR-0010](0010-distributed-semester-preparation.md) 取代。

历史决策曾把“设置向导完成”和“首次成功”作为两个不同状态。当前产品不再维护前者；首次成功仍然表示当前学期存在一张通过完整性检查、没有必排教学任务遗漏并已发布的课表。业务页面以一个可切换的“当前学期”作为默认上下文，历史或归档学期可查询和复制但默认只读，不应与当前教学工作混用。这样避免用户把完成学期准备误认为已经完成排课。

## 后果

- 仪表盘需要显示 P0 待办，直到当前正式学期首次发布课表。
- 切换到历史或非当前学期时，界面必须明确当前上下文，并限制常规写入和发布动作；只有内置系统管理员或教务主任可以切换当前学期。
- 示例数据体验不能悄悄改变正式学期的引导状态。

## 首屏引导顺序

首次发布前后的事实性提醒由仪表盘链接到对应业务页面，不占用额外的跨页面状态。仪表盘快捷入口按角色固定：教务主任和内置系统管理员进入排课工作台、课程表调整和版本与发布；教师进入课表查询、请假和通知。具体导航结构和通知视图见 ADR-0005、ADR-0016，角色权限见 ADR-0009。

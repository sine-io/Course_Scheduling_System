# 标准化教师安排导入隔离于规则和课表草稿

状态：已接受。

学校提供的教师安排文档结构不稳定，旧参考文件适配器还会同时处理规则和固定课位。系统选择由独立的教师安排模板导入模块接收版本化工作簿，而不把任意学校原始 Word、Excel 或扫描件直接交给生产导入流程；旧参考文件 API 仅保留兼容，不作为基础数据页的主要入口。

模板导入负责校验模板版本和目标学期、预览变更、处理三方冲突、原子写入和记录来源。只有通过导入记录明确关联的数据属于该来源；同名手工数据不会自动变成来源所有，来源中消失的数据也必须经过明确的保留或安全移除决策。

预览指纹同时覆盖工作簿、相关数据库状态、模板模式和用户决策；提交只接受与当前预览完全一致的指纹。每次成功导入均保留该组决策，逐行记录保留来源位置、原始值和已应用值，使冲突处理结果可以追溯。

领域文案使用“教室/场地”。由于 XLSX 工作表名禁止 `/`，自动排课准备模板中的对应工作表使用“教室及户外场地”，稳定字段键仍保持不变。

导入成功是一项数据事件，始终把学期排课就绪状态退回待确认。数据完整性与求解预检通过并由教务主任确认后，用户才进入规则编辑；模板导入不导入或激活排课规则，也不创建课表草稿。这样使来源维护、排课就绪、规则版本和课表草稿各自保留独立的权限、审计与生命周期边界。

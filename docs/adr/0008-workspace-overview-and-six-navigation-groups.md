# 工作空间首页总览与六分组导航

状态：已接受；取代 ADR-0005 中“五个侧栏功能分组”的数量决策。

侧边栏在“学期准备”之前增加“工作空间”分组，并提供独立的“首页总览”；原有仪表盘回到“学期准备”分组且继续作为登录和根路径默认页面。工作空间只对系统管理员、排课管理员和教务主任开放，教师不显示入口且后端拒绝读取其聚合数据。

首页总览通过当前学期已有事实聚合运行指标、重点事项和非阻断建议，不保存新的任务、建议或统计真相。目标课表优先选择最近更新的草稿，没有草稿时使用已发布课表；聚合结果只负责发现问题和导向现有业务页面，所有修改仍在原业务边界内完成。

## 后果

- 侧栏由工作空间、学期准备、排课主流程、日常运行、报表和系统管理六组组成，按角色过滤空分组。
- 工作空间与仪表盘承担不同职责：前者是管理角色的运行总览，后者继续提供所有角色可用的学期摘要和固定快捷入口。
- 首页总览不引入轮询或新的持久化模型；进入页面、切换当前学期和手动刷新时重新读取。
- 聚合接口必须执行与核心查看权限一致的后端授权，单个可派生检查失败不得清空其他可用区块。

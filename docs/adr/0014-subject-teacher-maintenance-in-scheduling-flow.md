# 在排课步骤中提供科目和教师档案视图

状态：已接受（流程设计）；关于基础数据页继续提供科目、教师高级维护的条款由 ADR-0017、ADR-0018 取代。

“排课工作台”作为主排课入口，在既有“科目节数”和“教师任课”步骤内分别提供科目档案/科目节数、教师档案/教师任课切换；日常录入不离开主流程，不增加流程步骤，也不创建第二套数据。第五步仍称“开始排课”，表示具体执行动作。工作台的“资源与导入”辅助工作面（复用基础数据组件）保留高级维护、导入、教师账号绑定和教室/场地维护；教室/场地不成为固定排课步骤，只有课程声明资源需求时才按需处理。

科目档案视图同时提供与基础数据手工录入页相同的“常用科目”逐项快捷添加。快捷项只作为当前学期科目档案的录入建议，用户确认后调用同一科目接口写入；不会按学段批量预置，也不会建立第二份科目数据。

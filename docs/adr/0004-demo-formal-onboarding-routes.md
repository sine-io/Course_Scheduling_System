# 示例体验与正式建校双路线

状态：已接受。

首次设置向导把新管理用户分成“体验示例数据”和“正式建校”两条持久化路线。路线选择
属于单校向导状态，排课管理员和系统管理员可以选择；示例数据只在明确选择示例路线、
且系统没有任何学期时创建。示例学期标记为 `is_demo`，不会参与正式首次成功判断。

系统管理页的示例数据入口仍保持系统管理员专属。这样既满足排课管理员首次学习完整
排课流程的入口，也不会扩大系统管理、备份恢复等运维能力的权限范围。正式学期一旦
存在，路线锁定为正式，示例接口拒绝写入；示例体验转正式时保留示例学期，新的正式
向导从已保存阶段重新开始。

## 后果

- 向导状态需要持久化路线，并在刷新、重新登录和中断后恢复。
- 示例上下文必须有可直接排课的作息、日期、准备状态和草稿课表，但不改变正式 P0
  待办或首次成功状态。
- 后端路线和学期上下文校验是最终边界，前端路线卡片只负责表达用户选择。

# 五步设置向导是唯一建校入口

状态：已被 [ADR-0007](0007-transparent-neutral-school-setup.md) 取代。

本文保留为历史决策记录。ADR-0007 继续采用单一初始设置入口，但将原步骤结构改为透明的四步流程，并把重新进入改为检查和补全当前学期。

全新管理用户进入系统后直接开始原有五步设置向导，不再先选择体验或建校路线。产品移除内置示例学校、示例学期标记和独立的“首次成功”状态；向导状态只记录当前步骤、完成状态和正在设置的学期，完成后进入教学任务管理。这样避免两套引导对同一建校过程给出冲突的完成含义，也让学期始终代表学校实际工作数据。

## 后果

- `/demo-data`、`/onboarding/route` 和 `/onboarding/status` 不再是产品接口；`wizard_state.route` 与 `semesters.is_demo` 从数据模型删除，学年与学期恢复普通唯一约束。
- 由于该能力尚未部署，迁移直接删除本地生成的示例学期，不提供示例数据升级或转正流程。
- 设置向导不常驻侧边栏；未创建学期时仪表盘保留“前往设置向导”，系统管理保留“重新执行设置向导”。
- Excel 导入模板中的教学示范行属于填写说明，不是可加载的示例学校数据，继续保留。

# 分散的学期准备页面取代设置向导

状态：已接受。

系统不再维护独立的设置向导、向导进度或“设置完成”状态。首次使用从“排课工作台”的学期创建卡片开始，创建真实学期，随后在工作台的学期管理、校历与准备、资源与导入辅助工作面及五步档案视图完成各自业务；仪表盘只显示当前学期的数据摘要，排课前置检查和排课准备确认继续作为排课领域的独立业务概念。这样避免一个跨页面流程同时拥有一套重复状态，也让首次准备与日常维护使用同一组页面和权限边界。

## 后果

- `/wizard`、向导 API 和向导持久化状态不再属于运行时产品；历史迁移仅用于解释旧数据库演进，最新迁移删除旧状态表。
- 空学期入口指向排课工作台的学期创建卡片；教室、教师账号、特殊日期等提醒分别指向工作台所属辅助工作面，不再汇总到一个完成页。
- “数据摘要”只表达当前学期已有数量，不推导“设置完成”或“可以排课”的结论；排课前置检查和排课准备确认保持各自的权威来源。
- 新部署和用户手册以排课工作台及其辅助工作面为起点；已有学期、校历和基础数据地址由 ADR-0018 提供兼容重定向，不重新引入旧导航入口。

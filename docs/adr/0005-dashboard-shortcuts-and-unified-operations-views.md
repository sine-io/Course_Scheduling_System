# 仪表盘快捷入口与统一运行工作面

状态：已接受；固定快捷入口、通知工作面、五组侧栏导航和系统管理边界有效。初始准备入口由 ADR-0010 取代。

侧边栏不再保存或展示个人“常用”入口，也不再使用“完整功能”包装层；仪表盘提供每个角色最多三个固定快捷入口。侧栏按学期准备、排课主流程、日常运行、报表和系统管理五组展示页面。通知和通知确认看板合并为同一通知工作面，操作角色通过视图切换进入确认看板，普通用户只看到自己的通知。系统管理、备份恢复和账号权限使用三个独立页面，并保留旧地址的重定向以兼容书签。

这样做是为了减少导航状态与权限状态的重复来源，同时保证高风险系统运维入口有清晰、可直达的页面边界。学期准备页面不合并成跨页面流程；无学期时可从仪表盘空状态进入学期页面。
